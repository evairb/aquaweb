# 🐟 Aquaweb

Sistema de compatibilidade de fauna e flora para aquaristas.
---

## ⚙️ Etapas do Processo

### ** Pré-requisitos **

| Tecnologia | Versão |
|------------------|----------------|
| **Python** | 3.12.6 |
| **Node Js** | v22.23.1 |

---

### **Backend**
---

**Etapas executadas:**
1. pip install -r requirements.tx
2. pip3 install --upgrade pip
3. python manage.py runserver 0.0.0.0:8000

---

### **Frontend**
---

**Etapas executadas:**
1. npm run dev
